# Протоколы здоровья 2026

Frontend-only сайт с доказательными протоколами здоровья. Проект не использует backend, базу данных, регистрацию или серверное хранение пользовательских данных.

## Что входит в текущий прототип

- главная страница с каталогом 13 протоколов;
- полноценные страницы всех 13 протоколов: от навигации и сна до контроля здоровья и подходов биохакеров;
- адаптивная версия для компьютеров и телефонов;
- авторские иллюстрации для каждого протокола;
- адаптивные объясняющие диаграммы: циркадный ритм, тарелочная модель, пищевые окна, движение, восстановление, цикл привычки, уход за кожей и волосами, добавки, здоровье зубов, измерения и фильтр биохакинга;
- оглавление, мобильное меню и индикатор чтения;
- статическая сборка для GitHub Pages.

## Публикация

Проект подготовлен для автоматической публикации через GitHub Pages. После загрузки в репозиторий нужно открыть `Settings → Pages` и выбрать `GitHub Actions` как источник публикации.

При каждом обновлении ветки `main` GitHub автоматически соберёт статическую версию и опубликует её.
